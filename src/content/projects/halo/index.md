A book inventory app with a React front end and a Flask REST API.

- **Categories, books and authors** modelled with SQLAlchemy on PostgreSQL.
- **Add, list and delete records** from a React interface talking to the Python API.

I wrote about building it:
[Crafting Harmony: building a full-stack web application with Flask and React](https://medium.com/@CraigryJames/crafting-harmony-building-a-full-stack-web-application-with-flask-and-react-deploying-to-heroku-4ff2599b94d5).
